# Карта Default из Python-референса

Вторая карта для обучения и ручной игры: «A Return to Simpler Times» (`default`) из Python-референса `C:/Disciples 2 python reference/Big_map/maps/default.py`. Текущая карта `number_grid_map.json` не изменилась: её случайные прогоны совпадают побитно с версией до доработки.

## Выбор карты

| Где | Текущая карта | Карта Default |
|---|---|---|
| Обучение | `benchmark_number_grid.py` | `benchmark_number_grid.py --map default` |
| Двойной щелчок | `run-train-numbergrid.cmd` | `run-train-numbergrid.cmd --map default` |
| Ручная игра | `open-numbergrid.cmd` | `open-numbergrid.cmd -Map default` |
| Сервер вручную | `serve_number_grid.py` | `serve_number_grid.py --map default` |

`--map` также принимает путь к JSON карты. В коде карта загружается через `load_map('current' | 'default' | путь)`. Переменная окружения `NUMBER_GRID_MAP` задаёт карту модуля `stoix.envs.number_grid` (`MAP`, `ACTION_NAMES`); тесты запускаются без неё. Результаты обучения на Default пишутся в отдельную папку `results/number_grid-50x50-…`. Если сервер игры уже запущен с другой картой, `open-numbergrid.cmd -Map default` сообщит об этом, а не откроет чужую карту.

Сеть для Default отдельная: у карт разные размеры наблюдения и смысл действий. Веса текущей карты на Default не загружаются.

## Как получена карта

`maps/default.json` создаёт скрипт:

```bash
python scripts/build_default_map.py --reference "C:/Disciples 2 python reference"
```

Источник — `Big_map/maps/default/layout.json`: снимок `reset(seed=0)` из `maps/default.py`. При повторных `enemy_id` действует последняя запись, всего 75 отрядов. Состав лавок взят из `maps/default.py` и `campaign_env_data.py`. Скрипт детерминирован: повторный запуск даёт тот же файл.

Координаты: в референсе `(x, y)`, в JAX `[строка, столбец] = [y+1, x+1]`. В JAX внешний ряд клеток всегда непроходим, поэтому сетка 48×48 стала 50×50.

## Цель

Победа, когда захвачены оба целевых города референса: Порт Полонис `[34, 29]` и Соругирилла `[26, 41]` (`maps/default.py:FINAL_OBJECTIVE_CITIES`, проверка `campaign_env_territory.py:_all_objective_cities_captured`). Город захватывается как обычно: герой входит в него живым после победы над охраной и гарнизоном. Остальные отряды, три других города и страж столицы для победы не нужны. Награда за победу та же: +3; бои, руины и прочие награды не изменились.

В JSON карты целевые города отмечены `"objective": true`. Если на карте нет отмеченных городов, действует прежнее правило текущей карты: все отряды, кроме стражей столиц, и все города с защитниками.

Скриптового бота столицы и распространения вражеской земли нет, как и просил пользователь.

## Вражеская столица

Столица Империи стоит в `[11, 27]`: площадь 5×5 непроходима, кроме ворот. На воротах стоит Мизраэль (900 HP, отряд 75 референса).

- В бою защитник получает +50 брони, как охрана города получает бонус форта.
- При отдыхе восстанавливает 15% поля + 35% столицы = 50% максимума.
- Атакующие и ослабляющие заклинания его не выбирают, как отряды городов и руин. Призыв может выбрать его ближайшей целью.
- Он не входит в цель. Победить его можно, но не обязательно.

Бонусы взяты из правил оригинала, те же, что у столицы игрока (+50 брони, +35%). В референсе `grid.py:76–77` для клетки столицы +40 брони и +50% восстановления.

Зелёный дракон (отряд 31 референса, `[47, 31]`) каждый день восстанавливается полностью, как в референсе (`campaign_env_magic.py:_heal_wounded_enemy_teams_for_turn`).

## Лавка заклинаний

Продаёт два заклинания по одной копии за 1000 золота. Купленное заклинание сразу считается изученным. Купить его можно, только если оно ещё не изучено.

- **Армагеддон** (Империя, V уровень): 125 урона Воздухом каждому бойцу ближайшего полевого отряда. Применение: 70 маны преисподней, 250 жизни, 80 смерти, 100 рун.
- **Призывание IV: Вердант** (Эльфы, V уровень): самый сильный энт сражается один с ближайшим отрядом. Применение: 110 жизни, 80 смерти, 50 рун, 250 маны эльфов.

Купленные заклинания применяет любой правитель, ограничение V уровня магом на них не действует (`campaign_env_magic.py:_is_spellbook_spell_blocked_by_typeoflord`). Изучить заклинание V уровня воин по-прежнему не может. Вердант не входит в книгу Империи, поэтому у него отдельное действие применения после собственной книги; лимит — одно применение в день. Подробности: [SPELL_CASTING.md](SPELL_CASTING.md#заклинания-из-лавки).

В референсе лавка продаёт Армагеддон и «Вызов Мстителя». По запросу пользователя второе заклинание — Вердант.

На карте нет источника маны эльфов, а Империя её не производит. Поэтому Вердант можно купить, но нельзя применить. Пользователь решил оставить карту как в референсе, без источника маны эльфов.

## Расхождения с референсом

| Что | Референс | JAX | Почему |
|---|---|---|---|
| Второе заклинание лавки | Вызов Мстителя | Вердант | запрос пользователя |
| Награда за целевые города | `reward_all_enemies` за первый, с множителем `FINAL_OBJECTIVE_CITY_REWARD_MULTIPLIER` за второй | +3 за победу | правила наград JAX |
| Бонусы стража столицы | +40 брони, +50% | +50 брони, +35% | правила оригинала, как у столицы игрока |
| Эликсир энергии / быстроты | 200 / 600 золота | 700 / 700 | цены JAX из GItem.VALUE |
| Zombie Talisman | 4000 | 400 | GItem.VALUE |
| Награды за боевые предметы | небольшие за экипировку и применение | нет | [правила](BATTLE_ITEMS.md) |
| Вода под объектами | 4 клетки | равнина | в JAX вода не может быть под объектом |
| Длина эпизода | 1800 шагов карты | 5000 шагов | правила текущей карты JAX |
| Скриптовый бот, вражеская земля | есть | нет | запрос пользователя |

Остальные правила (бой, опыт, доход, строительство, награды) те же, что на текущей карте: флаги скопированы из `number_grid_map.json`. Только на Default включены:
- боевые предметы героя (`battle_items: true`) и свиток, поэтому наблюдение v41 вместо v39;
- навыки героя по уровням, как в референсе (`hero_skills: true`): Нахождение пути, Мастер оружия и Мощь воина на 9 уровне ([правила](HERO_SKILLS.md));
- требования навыков к экипировке (`equipment_requires_skills: true`): знамя с 7 уровня, сапоги с 8-го, книга с 11-го, артефакты воин надевает сразу.

Навыки не меняют число действий и признаков.

### Сферы, талисман и свиток

Vampire Orb, Lich Orb, Orb of Life (по 800 золота), Zombie Talisman (400) и Mind ward scroll (600) лежат в сундуках X8–X11, X15, X16. Цены и игровые ID взяты из `GItem.dbf`. Сферы и талисман герой кладёт в два боевых слота и применяет в бою вместе с зельями Healing, Restoration, Ointment и Life: [правила](BATTLE_ITEMS.md). Свиток читает отряд героя после найма мага за 500 золота: [правила](SCROLLS_AND_STAVES.md).

## Проверки

`stoix/tests/number_grid_default_map_test.py`, в полном GPU-наборе:

- размеры, объекты, порядок действий и стартовый отряд;
- боевые предметы героя — отдельный файл `number_grid_battle_items_test.py` ([проверки](BATTLE_ITEMS.md#проверки));
- навыки героя: Мощь на 9 уровне, запас движения с Нахождением пути, экипировка воина по уровням, опыт Мастера оружия ([проверки](HERO_SKILLS.md#проверки));
- покупка Армагеддона: золото, запас лавки, бит знания, повторная покупка закрыта, воин применяет его по полной цене, цель — полевой отряд;
- покупка и применение Верданта: без маны эльфов недоступен, с ней начинается бой призыва;
- страж столицы: +50 брони в бою, восстановление 50%, полное восстановление дракона;
- цель: победа при двух целевых городах, пока живы остальные отряды; нет победы без второго целевого города; вход в последний целевой город после победы над его защитниками сразу завершает эпизод победой; без отмеченных городов страж столицы по-прежнему не входит в цель.

Случайные прогоны (32 среды × 400 шагов, случайные допустимые действия) на CPU: текущая карта даёт тот же хеш, что до доработки (`1623d71e…`). Карта Default проходит все проверки при построении среды: все объекты достижимы из столицы, входы лавок и руин открыты.

Полный CUDA-набор на GTX 1660 Ti, коммит `dc134f1`: **422 passed**, 0 упавших. С тёплым кешем pytest 758,7 с, **833,1 с** от запуска команды при лимите 900 с. Тесты карты Default занимают 15,0 с (40,9 с при холодной компиляции).

После смены цели (коммит `9f9b602`) полный набор в `C:\jaxjax` остановился по лимиту 900 с: 267 passed, 0 упавших. Кеш компиляции этой папки собран до слияния применения заклинаний, поэтому 53 программы перекомпилировались; прежний полный прогон здесь (`spell-research-20261010`) тоже упёрся в лимит. Оставшиеся 12 файлов, начиная с `number_grid_reference_actions_test.py`, прошли отдельно: **200 passed** за 542,8 с. Упавших тестов нет.

## Скорость

Замер 10 октября 2026 на GTX 1660 Ti: два раунда в порядке до доработки (`c06839d`), после (`dc134f1`), затем карта Default. Learner — тестовый запуск на 1 млн переходов, seed 42.

| Параметры сети | 492 518 | 492 518 | | 685 542 |

Текущая карта не замедлилась: её прогоны побитно те же, а +5,8% learner — разброс между запусками. Default обучается не медленнее текущей карты, хотя наблюдение больше на 754 признака: сама среда на ней быстрее. При случайных действиях бои на Default занимают 28% шагов, на текущей карте 9%. Часы WSL в этом запуске отставали примерно на 5%, поэтому абсолютные значения завышены; сравнение внутри сессии корректно. [Протокол](validation/default-map-performance.json).

Смена цели на два города, тот же день и GPU: learner на Default 1 млн, seed 42 — **96 162 → 98 565** переходов/с (+2,5%), компиляция PPO 60,7 → 57,3 с. Замедления нет. Первое обучение с новой целью (50 млн) выигрывает 91% эпизодов argmax: [LOCAL_RESULTS.md](../LOCAL_RESULTS.md).
