# NumberGrid 24×24 — PPO на вашей видеокарте

Восстановление NumberGrid из описания [Alian3785/jaxrep](https://github.com/Alian3785/jaxrep). Подготовлено для **NVIDIA GeForce GTX 1660 Ti, 6 ГБ**, Windows + WSL2 Ubuntu 24.04. Обучение: обычный **Stoix Anakin feedforward PPO без рекуррентной памяти**. Navix и Craftax не устанавливаются и не запускаются.

Карта, среда, обучение, сохранение весов и автономная интерактивная визуализация восстановлены заново. Удалённых исходников и checkpoint в публичном репозитории не было. Полные правила и принятые решения: [NUMBER_GRID.md](NUMBER_GRID.md). Оригинальное описание сохранено в [README_REMOTE_ORIGINAL.md](README_REMOTE_ORIGINAL.md).

Текущая карта: **24×24, 12 неподвижных врагов**, числа случайно назначены один раз в диапазоне 1–12; обязательно есть 1 и 12 и проходимая цепочка роста **с 2 до 13**. Случайные наборы с числовым тупиком отбрасываются при подготовке карты. Агент начинает с **2**. При сбросе карта и числа сохраняются. За каждый ход вычитается **0,001 награды**, за первое посещение новой клетки в эпизоде начисляется **+0,01**. Повторные визиты, начальная клетка и ходы с поражением бонуса не дают. История посещений сбрасывается в новом эпизоде; в ручной игре посещённые клетки зелёные. Движение, контакты, награды за врагов и лимит 2000 ходов прежние. Среда и PPO выполняются end-to-end на JAX/GPU.

## Открыть игру

Для текущей карты включена **маска ходов в стены** (`mask_walls: true`). Штатный `AddActionMaskWrapper` добавляет её к наблюдению; актор применяет маску при выборе действия и обучении PPO. Диагонали в стены тоже исключены. Занятые клетки и опасные противники остаются доступны по прежним правилам. В ручной игре соответствующие кнопки отключены, клавиши не расходуют ход. Сеть получает прежние 52 физических признака; её размер сохранён.

Откройте **`open-numbergrid.cmd`** или **`viewer.html`**. Есть просмотр настоящих записей PPO, перемотка, выбор скорости и ручная игра. Интернет и сервер не нужны. Для ручной игры: W/A/D/X или стрелки — прямо; Q/E/Z/C — диагонали; R — сначала. Клавиши определяются по физическому положению, в том числе на русской раскладке. На экране доступны восемь кнопок.

## Обучение

В этом компьютере отдельное окружение Python находится в `/home/minigrid/.venvs/numbergrid-cuda13`. JAX/jaxlib **0.11.2**, CUDA runtime **13.4.92**, Flax **0.12.10**. Старые окружения MiniGrid сохранены отдельно. Linux-драйвер NVIDIA внутрь WSL устанавливать не требуется.

Из PowerShell в `C:\jaxjax`:

```powershell
wsl -d Ubuntu-24.04 -u minigrid --cd C:\jaxjax -- bash scripts/run_gpu.sh benchmark_number_grid.py --output results/number_grid-24x24-wall-mask-repeat
wsl -d Ubuntu-24.04 -u minigrid --cd C:\jaxjax -- bash scripts/run_gpu.sh export_number_grid.py --results results/number_grid-24x24-wall-mask-repeat
```

По умолчанию — **ровно 5 млн переходов**, seed 42. Повторно использовать заполненную папку результатов нельзя: укажите новый `--output`. `--smoke` выполняет отдельную короткую проверку на 250 тысяч переходов. Все параметры и измерения сохраняются вместе с весами; скорость включает сбор данных и PPO, а компиляция измеряется отдельно.

Последний проверочный запуск — **20 млн переходов с нуля с бонусом за исследование и маской стен**, сохранён в `results/number_grid-24x24-exploration-wall-mask-optimized-20m/`; его записи встроены в `viewer.html`. Скорость **702 434 перехода/с**; в повторной сопоставимой паре контроль без маски — **696 606 переходов/с**, потери 7% нет. **1024/1024 побед argmax за 91 ход**, при сэмплировании **1023/1024 побед** на той же фиксированной карте. Это результат конкретного запуска: повторный контроль без маски тоже смог обучиться. Предыдущие результаты сохранены отдельно. Для повторения используйте `--total-timesteps 20000000` и новый `--output`.

Артефакты последнего запуска в `results/number_grid-24x24-exploration-wall-mask-optimized-20m/`: `results.json`, `config.json`, `map.json`, `packages.txt`, `metrics.csv`, `params.msgpack`, `learner_state.msgpack`, `trajectories.json`. Качество и скорость этого компьютера приведены в [LOCAL_RESULTS.md](LOCAL_RESULTS.md). Прежняя карта сохранена в `maps/number_grid-16x16.json`, её модель — в `results/number_grid/`. Для повторного замера старой карты используйте `--map maps/number_grid-16x16.json` и отдельный `--output`.

## Установка и проверки

На этом компьютере установка выполнена; при необходимости откройте `setup-numbergrid.cmd`. На Linux с Python 3.12 и совместимым NVIDIA-драйвером:

```bash
bash scripts/install_runtime.sh
bash scripts/run_gpu.sh -m pytest -q
bash scripts/run_gpu.sh benchmark_number_grid.py
bash scripts/run_gpu.sh export_number_grid.py
node verify_number_grid_viewer.cjs
```

`NUMBERGRID_VENV` позволяет выбрать другой путь к окружению. Launcher явно требует CUDA; незаметного перехода на CPU нет. Зависимости закреплены в `numbergrid-runtime.txt` и `runtime-constraints.txt`. Исходники подключаются через Python path; сборка пакета на Windows-разделе WSL не требуется.

## Исходники и лицензии

Полные исходники Stoix: `8fff19c94a478c1e1ff75fbf10396d488aa25d70`, документация — `README_STOIX.md`. Stoa: `b3a084ed05893c301e079a8f527de90513896d7e`, каталог `stoa-src/`. Исходный learner PPO сохранён без изменений. Локальные изменения: регистрация NumberGrid, обработка словаря наблюдений и маски в FeedForwardActor/Critic и CategoricalHead, инициализация булевых ArraySpace в Stoa, необязательные зависимости logger, измеритель и интерфейс. Другие алгоритмы в upstream-исходниках не настроены и их дополнительные зависимости не устанавливаются.

Исходные манифесты Stoix сохранены как `pyproject.upstream.toml` и `uv.upstream.lock`; они описывают upstream, а не локальный runtime. Лицензии сохранены в `LICENSE` и `stoa-src/LICENSE`. Полный источник описания: [публичный репозиторий](https://github.com/Alian3785/jaxrep).
